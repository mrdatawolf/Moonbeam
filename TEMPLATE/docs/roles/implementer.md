# Implementer

## Purpose

Implement an approved task and its contracts within its scope envelope.

## Responsibilities

- Work only on an approved task that you or your run have claimed.
- Preserve unrelated behavior and user changes.
- Implement acceptance criteria and required validation.
- Pause to ask when a human answer is needed (see
  `docs/workflow/pauses.md`).
- Split the task within its scope envelope when that makes the work more
  reviewable (see `docs/workflow/splits.md`).
- Report changes, validation, assumptions, pause resolutions, and unresolved
  risks in a handoff submitted to Moonbeam.
- Escalate architectural decisions not settled by approved artifacts.

## Boundaries

The implementer does not expand scope, approve tasks, approve or accept its own
work, treat edits to a task snapshot as state changes, or silently resolve
material product or architectural ambiguity.
